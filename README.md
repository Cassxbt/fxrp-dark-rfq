# FXRP Dark RFQ

Sealed-bid RFQ matcher for FXRP, settling on Coston2. Matching happens privately inside a Flare Confidential Compute (FCC) TEE extension; the chain only sees the fill.

Built for [Flare Summer Signal](https://dorahacks.io/hackathon/flaresummersignal/detail) — Bounty 2 (Confidential Compute) primary, Bounty 1 (Interoperable Assets / FXRP) as integration proof.

Full design, trust model, and known limitations: see the build spec in the private planning repo (linked in the DoraHacks submission). This README will be filled in with setup/run instructions as the extension and contract are built.

## Status

In progress. FCC scaffold deploy attempt in progress on Coston2.
